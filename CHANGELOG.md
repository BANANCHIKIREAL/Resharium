# История изменений

## 1.1.0 — 2026-09-03

- добавлена автоматическая проверка и установка обновлений из GitHub Releases;
- выбор класса заменён встроенным тёмным меню;
- анимация главной иллюстрации переведена на плавные GPU-трансформации;
- запрещено случайное выделение текста интерфейса, но выделение в полях ввода сохранено;
- удалены блок «Учитесь осознанно» и подпись «Сначала подумай — потом проверь».

## 1.0.9 — 2026-09-03

- из формы добавления решения убрано обязательное поле «Номер задания»;
- название выбранного учебного раздела сохраняется автоматически.

## 1.0.8 — 2026-09-03

- добавлены Google OAuth и фотография Google-профиля;
- добавлена отдельная современная иконка гостя;
- подключены Supabase Auth, Realtime, пользовательские подборки и модерация ссылок;
- добавлены настоящие favicon четырёх белорусских источников;
- добавлена проверка доступности источника по классу и предмету;
- расширен каталог белорусских школьных предметов с 1 по 11 класс;
- исправлены прокрутка, переполнение, перекрытие системной панели и прозрачность иконки приложения;
- ссылки на решения открываются во встроенном просмотрщике.
