# История изменений

## 1.4.2 — 2026-09-06

- Обновления больше не скачиваются и не устанавливаются автоматически.
- Кнопка обновления отдельно проверяет, скачивает и устанавливает выбранную версию.

## 1.4.1 — 2026-09-06

- 37 размытых миниатюр Resheba заменены чёткими фирменными обложками Решариума;
- для одного недоступного изображения с ошибкой 404 также включена фирменная обложка;
- при будущей ошибке загрузки изображения карточка автоматически переключается на чёткий запасной вариант.

## 1.4.0 — 2026-09-06

- крупные панели получили аккуратный стеклянный эффект, а карточки — лёгкие полупрозрачные поверхности без тяжёлого размытия;
- добавлен живой фоновый свет с фиолетовым, голубым и розовым оттенками;
- обложка плавно перелетает из карточки в окно учебника при открытии;
- на Android прозрачность окна учебника усилена для читаемости;
- новые эффекты отключаются при системной настройке уменьшения анимации.

## 1.3.2 — 2026-09-05

- интерфейсные иконки заменены на SVG из набора Lucide через Morphicons;
- добавлено плавное превращение иконок избранного, навигации, списка классов и состояний обновления;
- новый набор работает офлайн на Windows и Android и учитывает системную настройку уменьшения анимаций;
- сохранены фирменные логотипы Google и сайтов-источников.

## 1.3.1 — 2026-09-04

- установщик Windows теперь автоматически завершает только процесс приложения перед заменой файлов;
- устранён повторяющийся диалог «Не удалось закрыть Решариум» при обновлении;
- установщик очищает ошибочно попавший в старые версии Android build-кэш с чрезмерно длинными путями;
- в регистрации добавлена повторная отправка письма подтверждения с безопасным таймером;
- ошибки ограничения частоты писем Supabase теперь показываются понятным сообщением.

## 1.3.0 — 2026-09-04

- каталог заменён на 153 реальные карточки учебников и тетрадей с Resheba.top для 2–11 классов;
- обложки, авторы, годы и прямые ссылки на страницы учебников загружаются из Supabase с офлайн-копией внутри приложения;
- избранное и пользовательские подборки синхронизируются между устройствами через защищённые RLS-правила Supabase;
- на Android добавлена проверка GitHub Releases и загрузка нового подписанного APK;
- исправлено перекрытие карточки учебника и окна входа нижней навигацией;
- белое свечение обложек заменено на цветное свечение в оттенке карточки.

## 1.2.0 — 2026-09-04

- добавлена версия приложения для Android 7 и новее;
- интерфейс адаптирован под экран телефона, вырезы и нижнюю навигацию;
- сайты решений и Google-вход открываются внутри приложения;
- возврат после Google OAuth обрабатывается через ссылку приложения;
- добавлены фирменные Android-иконки и тёмный экран запуска;
- подготовлен подписанный APK для установки и будущих обновлений.

## 1.1.2 — 2026-09-03

- автор может удалить собственную ссылку после её одобрения или отклонения;
- администратор может удалять ссылки прямо из очереди и истории модерации;
- в карточках решений и профиле показывается favicon сайта-источника вместо стандартной иконки.

## 1.1.1 — 2026-09-03

- убрана дублирующая кнопка «Профиль» из основного меню;
- профиль остаётся доступен через карточку пользователя внизу боковой панели;
- добавлена серверная защита Supabase от спама и обхода модерации;
- введены лимиты: 5 ссылок в час, 20 в сутки, 50 ожидающих и 500 сохранённых на аккаунт;
- ограничены размеры подборок: 30 подборок, 100 учебников в одной и 500 учебников суммарно;
- дубликаты активных ссылок блокируются, а служебные поля публикаций задаются только сервером.

## 1.1.0 — 2026-09-03

- добавлена автоматическая проверка и установка обновлений из GitHub Releases;
- выбор класса заменён встроенным тёмным меню;
- анимация главной иллюстрации переведена на плавные GPU-трансформации;
- запрещено случайное выделение текста интерфейса, но выделение в полях ввода сохранено;
- удалены блок «Учитесь осознанно» и подпись «Сначала подумай — потом проверь».

## 1.0.9 — 2026-09-03

- из формы добавления решения убрано обязательное поле «Номер задания»;
- название выбранного учебного раздела сохраняется автоматически.

## 1.0.8 — 2026-09-03

- добавлены Google OAuth и фотография Google-профиля;
- добавлена отдельная современная иконка гостя;
- подключены Supabase Auth, Realtime, пользовательские подборки и модерация ссылок;
- добавлены настоящие favicon четырёх белорусских источников;
- добавлена проверка доступности источника по классу и предмету;
- расширен каталог белорусских школьных предметов с 1 по 11 класс;
- исправлены прокрутка, переполнение, перекрытие системной панели и прозрачность иконки приложения;
- ссылки на решения открываются во встроенном просмотрщике.
