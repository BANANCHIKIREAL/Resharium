# Решариум

Решариум — приложение для Windows и Android для школьников Беларуси, в котором можно находить решения заданий из разных белорусских ГДЗ-сайтов.

В приложении есть каталог учебников по классам и предметам, поиск решений, встроенный просмотр сайтов, избранное, собственные подборки учебников и пользовательский профиль.
