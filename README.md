# Решариум

Настольное Windows-приложение-каталог ссылок на решения школьных заданий. Оно не копирует страницы сторонних сайтов: карточка задания открывает исходную страницу во встроенном защищённом просмотрщике.

## Что работает

- расширенный белорусский каталог предметов и фильтры для всех классов с 1 по 11;
- карточки учебников, избранное и локальный профиль;
- фотография Google-профиля после входа и отдельная иконка гостя;
- добавление безопасных HTTP(S)-ссылок на решения;
- поиск задания по четырём белорусским источникам: Resheba.top, gdz.by, gdz-online.by и MegaResheba;
- проверяемая матрица доступности «класс + предмет»: неподходящие источники не показываются;
- настоящие favicon источников в карточке и при выборе сайта;
- встроенный просмотр сайтов без перехода во внешний браузер;
- собственные сохраняемые подборки предметов и учебников;
- локальная работа без регистрации;
- аккаунт по email через Supabase;
- вход через Google и фотография Google-профиля;
- общие решения, модерация публикаций и обновления через Supabase Realtime;
- нативная Electron-оболочка и Windows-установщик.

## Подключение Supabase

Приложение уже подключено к отдельному проекту Supabase «Решариум» безопасным публичным ключом. Схема из [`supabase/schema.sql`](supabase/schema.sql) применена, пользовательские таблицы защищены RLS.

Для Google-входа:

1. В Google Cloud создайте OAuth Client типа Web application и добавьте callback URL `https://bdfghggtvtnedakrocbu.supabase.co/auth/v1/callback`.
2. В Supabase включите Google provider и вставьте Client ID и Client Secret.
3. В Authentication → URL Configuration → Redirect URLs добавьте `resharium://auth/callback`.

Для собственной сборки создайте проект в [Supabase](https://supabase.com/dashboard), выполните `supabase/schema.sql` в SQL Editor и замените Project URL и `publishable key` в `src/lib/supabase.ts`.

Официальные инструкции: [Google login](https://supabase.com/docs/guides/auth/social-login/auth-google), [Redirect URLs](https://supabase.com/docs/guides/auth/redirect-urls), [Postgres Changes](https://supabase.com/docs/guides/realtime/postgres-changes).

## Безопасность и права

- В клиенте используется только publishable key; `service_role` запрещён.
- В `public`-таблицах включён RLS. Новая общая ссылка получает статус `pending` и становится публичной только после одобрения администратора.
- Автор может изменять или удалять собственную ссылку, пока она ожидает проверки; администратор может одобрить её либо отклонить с обязательным указанием причины.
- Администраторы хранятся в закрытой схеме `private`; роль назначается вручную только после регистрации пользователя.
- Перед подключением стороннего сайта проверьте его условия использования. Названия и favicon источников используются только для идентификации; права на них принадлежат соответствующим владельцам.
