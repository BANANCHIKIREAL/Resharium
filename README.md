# Решариум

Решариум — приложение для Windows и Android для школьников Беларуси, в котором можно находить учебники и решения заданий из белорусских ГДЗ-сайтов.

В приложении есть каталог реальных учебников по классам и предметам, поиск решений, просмотр сайтов внутри приложения, избранное, собственные подборки учебников и пользовательский профиль.
